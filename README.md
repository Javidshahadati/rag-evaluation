# RAG Evaluation

## 📌 توضیح
ارزیابی سیستماتیک یک سیستم RAG (Retrieval-Augmented Generation) برای سنجش دقت و میزان توهم (Hallucination).

## 🎯 هدف
- سنجش دقت RAG روی سوالات **در متن**
- سنجش دقت RAG روی سوالات **خارج از متن**
- شمارش تعداد **توهم** (جواب‌های ساختگی)

## 🛠️ تکنولوژی
- Sentence Transformers (Embedding چندزبانه)
- FAISS (پایگاه برداری)
- Qwen2.5-1.5B-Instruct (مدل زبانی)
- Kaggle (GPU T4)

## 📊 معیارهای ارزیابی
| معیار | توضیح |
|--------|--------|
| **درست؟** | آیا جواب مدل با جواب انتظاری مطابقت دارد؟ |
| **از متن؟** | آیا جواب از متن بازیابی‌شده آمده؟ |
| **توهم؟** | آیا مدل جوابی ساخته که در متن نیست؟ |

## 📝 نتایج مورد انتظار
- دقت روی سوالات در متن: **۱۰۰٪**
- دقت روی سوالات خارج از متن: **۱۰۰٪** (همه «در متن نیست»)
- تعداد توهم: **۰**
