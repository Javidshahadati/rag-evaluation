# RAG Evaluation

## 📌 توضیح
ارزیابی سیستماتیک یک سیستم RAG (Retrieval-Augmented Generation) برای سنجش دقت و میزان توهم (Hallucination).

## 🎯 هدف
- سنجش دقت RAG روی سوالات **در متن**
- سنجش دقت RAG روی سوالات **خارج از متن**
- شمارش تعداد **توهم** (جواب‌های ساختگی)

## 🛠️ تکنولوژی
- Sentence Transformers (Embedding چندزبانه)
- FAISS (پایگاه برداری)
- Qwen2.5-1.5B-Instruct (مدل زبانی)
- Kaggle (GPU T4)

## 📊 نتایج نهایی
| معیار | نتیجه |
|--------|--------|
| دقت روی سوالات در متن | **۵/۵ = ۱۰۰٪** |
| دقت روی سوالات خارج از متن | **۳/۳ = ۱۰۰٪** |
| **دقت کلی** | **۸/۸ = ۱۰۰٪** |
| **تعداد توهم** | **۰** ✅ |

## 📋 جدول ارزیابی کامل
| سوال | در متن | درست؟ | توهم؟ | فاصله |
|-------|--------|--------|--------|--------|
| Transformer چیست؟ | ✅ | ✅ | ✅ | ۱۸.۵۰ |
| تفاوت BERT و GPT | ✅ | ✅ | ✅ | ۱۴.۹۳ |
| Overfitting یعنی چه؟ | ✅ | ✅ | ✅ | ۱۱.۱۲ |

| CNN برای چه کاری | ✅ | ✅ | ✅ | ۱۸.۳۷ |
| پایتخت فرانسه | ❌ | ✅ | ✅ | ۴۹.۳۰ |

| بهترین فیلم تاریخ | ❌ | ✅ | ✅ | ۳۳.۶۷ |

## 💡 نکته‌ی مهم
فاصله (distance) برای سوالات **خارج از متن** (۳۳ تا ۴۹) بسیار بالاتر از سوالات **در متن** (۱۱ تا ۱۸) است. این نشان می‌دهد مدل به‌درستی تشخیص می‌دهد که سوال به متن ربطی ندارد.

## 📝 درس‌های گرفته‌شده
- **ارزیابی با سوالات خارج از متن** بهترین راه تشخیص توهم است.
- فاصله‌ی بالا = احتمالاً سوال به متن ربطی ندارد.
- مدل دستورپذیر با `system_prompt` خوب، توهم نمی‌زند.
- در محصولات تجاری، «توهم صفر» هدف اصلی است.
